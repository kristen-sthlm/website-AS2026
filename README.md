# Andliga Sånger

Den digitala utgåvan av sångboken Andliga Sånger, 2026.

Built with [Eleventy](https://www.11ty.dev/) and hosted on GitHub Pages.

## Local development

Requires Node.js 20 or later.

```bash
npm install
npm run serve   # local preview at http://localhost:8080
npm run build   # production build into _site/
```
## Deployment

Pushing to the `main` branch triggers a GitHub Actions build that deploys to GitHub Pages.

To enable Pages on a fresh repo:

1. Settings → Pages → Source: **GitHub Actions**
2. Push to `main`. The site appears at `https://<user>.github.io/<repo>/`.
