# 1.
Jerusalem, Guds stad,
I tron vi skåda dig.
Vid tanken på din härlighet
Vårt hjärta fröjdar sig.

# 2.
Du trygga vilohamn,
Där snart vi vila få,
Där fritt vår själ åtnjuta skall
Allt vad hon här åtrår.

# 3.
Vem kan förklara här
Den fröjd oss väntar då,
När vi med alla helgonen
Dig, Herre, prisa få.

# 4.
Ej tunga ’tälja kan,
Vad fröjd det blir och ro
I evigheters evighet
Hos Gud och Lammet bo.

# 5.
Det ”dolda manna” då,
Känt uti öknen här,
Guds Son, det levande Guds bröd,
Oss ständigt närer där.

# 6.
Gud själv och Lammet då
Skall ljus och tempel bli,
Och frälsta skaror fullt förstå
Guds hemlighet däri.
