# 1.
O Herre, då din kärlek är
Så stor, så rik, så fri,
Må våra hjärtan, våra liv,
Uppfyllas helt av Dig.

# 2.
Vi älska Dig för vad Du är,
För allt vi hos Dig se,
Vi älska Dig för korsets död,
Vår Återlösare,

# 3.
Fastän Du Fadren jämlik var
Och i Guds skepelse,
Du sänkte Dig till jorden ned
Och blev en tjänare.

# 4.
Du ville bliva män’skor lik
Och Dig utgiva här,
Att lika Dig vi måtte bli
Och se Dig som Du är.

# 5.
O Jesus Krist, Du för din Gud
En ljuvlig vällukt är;
Din kärlek stor ny kraft, nytt mod
Och glädje oss beskär.

# 6.
Giv att i kärlek, mildhet, tro
Lik Dig vi bliva må,
Tills ansikte mot ansikte
Dig själv vi skåda få.
