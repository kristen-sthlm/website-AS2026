# 1.
There is but one way that leads to heaven,
There is but one path where the Father is reached,
There is but one river which is the river of life,
And the way there is the Lord Jesus Himself.

# C.
Jesus is the way, the only way,
Lovingly He calls, as Scripture teaches us:
Whosoever will, come today unto Me,
My life on the cross I gave out for thee!

# 2.
There is but one name that has life in itself,
In this name thou receivest salvation free.
There is but one bread which is the bread of life,
For the Prince of life was dead upon the cross.

# 3.
There is but one city which God Himself has built,
But one sorrowless home where one rests securely.
There is but one light that never goes out,
A heavenly joy that never ends.

# 4.
There is but one hand that can do all things,
There is but one haven where no storms reach,
There is but one hope that is sure and steadfast,
Our blessed hope is the Lord Jesus Christ.
