# 1.
Fader uti härligheten
Skåda vi din käre Son,
Upphöjd vid din högra sida,
Rikligt lönt för jordens hån.

# 2.
På din tron, o Gud, vår Fader,
Han som män’ska sitter krönt,
Han som törnekronan burit
Och härnere smälek rönt.

# 3.
Honom änglarna beundra,
Han din vilja uppfyllt här,
Varje tunga skall bekänna:
Jesus allas Herre är.

# 4.
Gud och Fader, våra hjärtan
Lovets offer bringa Dig
För din Son, som Du utgivit.
Pris ske Dig evinnerlig!
