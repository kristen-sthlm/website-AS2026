# 1.
Jesu blod för oss har banat
Vägen fram till Gud.
Lycklig den, som nu anammar
Nådens bud.

# 2.
Endast genom detta blodet
Sker förlåtelse.
Gud åt alla fri benådning
Nu kan ge.

# 3.
Ja, den brottsling, som i synden
Annars måste dö,
Genom Jesu blod kan bliva
Vit som snö.

# 4.
Nu den Helige vi nalkas
Med ett heligt mod;
Ty åt Gud har Jesus köpt oss
Med sitt blod.

# 5.
Vem kan fatta blodets värde,
Denna helga ström,
Som förkunnar än Guds kärlek,
Djup och öm!

# 6.
Herre Jesus, Dig vi tacka
För ditt dyra blod,
Du, som gav ditt liv för fåren,
Herde god!
