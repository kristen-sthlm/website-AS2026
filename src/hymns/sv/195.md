# 1.
Du, som av kärlek dog,
Jesus, för mig,
Intet jag håller då
Undan för Dig;
Nej, tag mig Herre fatt
Så med din kärlek, att
Hjärtat må offra glatt
Allting för Dig.

# 2.
Du, som till nådastol
Utgavs för mig,
Herre, av nåd mig giv
Kraft ifrån Dig,
Nöjd med mitt kors att gå,
Prisande Dig, och så
Göra, fast svagt, ändå
Något för Dig.

# 3.
Herre, förnya städs’
Din kraft i mig,
Att jag må varje stund
Leva för Dig,
Vinnande något får,
Helande något sår,
Görande, var jag går,
Allting för Dig.

# 4.
Du har med kraftig hand
Helt fattat mig;
Dragen av kärleksband,
Följer jag Dig;
Och när i himlens höjd
Jag får Dig se med fröjd,
Njuter jag, evigt nöjd,
Allting med Dig.
