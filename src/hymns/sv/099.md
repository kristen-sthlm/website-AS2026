# 1.
Vår Fader, vi komma som lyckliga barn
Inför Dig att giva Dig ära.
För allt vad din Ande oss kungjort om Dig
Av hjärtat vi lov Dig hembära
Och glädjas att vara Dig nära.

# 2.
Tack, Fader, för Kristus, din älskade Son,
Som kom att för oss uppenbara
Ditt hjärtelag, sådant av ålder det var
Och sådant det alltid skall vara!
Han kom all din nåd att förklara.

# 3.
I Sonen, som här i ditt ansiktes ljus
Som ”Telning” inför Dig upprunnit,
I Honom, som templet uppbygger åt Dig,
Din kärlek sin vila har funnit.
Åt Dig har Han härlighet vunnit.

# 4.
Vad fröjd att se hä’n mot den dag, då hans lov
Skall högt genom rymderna skalla,
Då jublande skaror, som prisa ditt namn,
Tillbedjande för Dig nedfalla
Och Kristus blir erkänd av alla.
