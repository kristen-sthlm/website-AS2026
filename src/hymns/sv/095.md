# 1.
Gud vare tack, som oss segern har givit
Genom vår Frälsare, mäktig och god!
Gud vare tack, att vi renade blivit
Genom vårt påskalamms heliga blod!
Gud vare tack för det levande hopp,
Som över döden och graven gått opp
Genom den Uppståndnes seger!

# 2.
Pris Dig, o Kristus, för ljus över griften;
Pris för ditt löfte, din heliga frid!
Pris Dig, som talar till oss genom skriften,
Stärker vårt hjärta i prövningens tid!
Pris Dig, att öppnade ögon vi få,
Att vi Dig se och igenkänna må,
Du, som var död och som lever!
