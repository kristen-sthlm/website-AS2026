# 1.
O Jesus, så ljuvligt uppfylles vårt bröst
Vid tanken på Dig och ditt namn!
Mer ljuvligt det blir dock att höra din röst
Och vila i ro i din famn.

# 2.
Ej klaraste röster, ej klingande malm
Kan giva ett skönare ljud,
Än när vi få höra ditt signade namn,
O människors Frälsare, Gud!

# 3.
Till Dig de betungades hjärtan sig vänt,
De ödmjukas glädje Du är.
Din mildhet mot alla som bedja vi känt,
Din godhet vi erfarit här.

# 4.
Din kärlek, o Herre, all fröjd den kan ge,
Ej tunga kan uttala här,
Ej penna kan ’tälja, det veta blott de,
Som tillhöra Dig, Herre kär.

# 5.
O Jesus, vår eviga glädje Du är,
Vår segerlön bliva Du skall!
Må Du bli vår ära på vandringen här
Och sedan i evighet all!
