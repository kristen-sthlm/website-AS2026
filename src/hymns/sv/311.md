# 1.
Hör, millioners sälla skara
Sjunger Lammets pris, ack hör!
Tusen sinom tusen svara
Likt ett eko, som ej dör.

# 2.
”Pris ske Lammet!” så de sjunga,
Sången fyller himlens rum;
Högt och vitt omkring var tunga
Prisar evangelium.

# 3.
Samma lovsång, som där klingar
Evigt kring Gud Faders tron,
Lammet ock sitt offer bringar
I fullstämmig, enig ton.

# 4.
Allt åt Sonen hyllning giver,
Lik den hyllning Fadren har;
Sedd i Sonens klarhet bliver
Fadrens ära uppenbar.

# 5.
Av Guds Helge Ande lära
Helgonen, att Jesus har
All gudomlig makt och ära,
Han, som evigt är och var.

# 6.
Hör de toner underbara,
Huru de lovsjunga där!
”Amen!” himlens höjder svara,
”Amen!” jordens dalar här.
