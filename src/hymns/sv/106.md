# 1.
Ack, vem kan tillfyllest prisa,
Store Gud, din godhet här!
Alla dina verk bevisa,
Att den outsäglig är.

# 2.
Vem din kärlek kan beskriva,
Vem din nåd, o Fader huld,
Då vi se Dig Sonen giva
Att försona all vår skuld.

# 3.
Vem din trofasthet kan mäta,
Jesus, Du vår löftesman!
Kan en mor sitt barn förgäta,
Du oss ej förgäta kan.
