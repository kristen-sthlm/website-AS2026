# 1.
Än finns det rum! Se öppen är ännu
Guds fadersfamn, o själ, hvi dröjer du?
Snabbt ilar tiden, nådens dag tar slut;
Besinna dig, ty nu går ropet ut:
Än finns det rum!

# 2.
All himlens sällhet bjuds dig nu: gå in!
O, skynda, ty blott denna dag är din,
Din frälsningsdag, då Herren ger dig tid
Att söka det, som tillhör evig frid.
Än finns det rum!

# 3.
Allt är fullkomnat; vägen öppen är
Till nådastolen: lägg din börda där!
Där finnes frid för skuldbelastad själ,
En evig frälsning för var syndaträl.
Än finns det rum!

# 4.
Snart nådens dörr stängs till, och om du då
Står utanför: ej rum finns mer att få.
Och Han, som här så milt dig bjuder: kom,
Skall då dig visa bort till evig dom;
Men nu finns rum.
