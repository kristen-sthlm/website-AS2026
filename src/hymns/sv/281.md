# 1.
Vila i hemmet hos Herren,
Fjärran från kamp och strid,
Redan i hoppet den skänker
Troende hjärtat frid.

# C.
Jesus, hos Dig finnes vila,
Eviga sabbatsro;
Ack, snart efter stormen och striden
Vi skola hos Dig få bo.

# 2.
Ängeln med svärdet är borta,
Öppen står Edens port,
Ögat, fast tårarna rinna,
Ser dock den sköna ort.

# 3.
Över det lidande hjärtat
Lyser den klara dag,
Låter det prövade barnet
Nöjas med Guds behag.

# 4.
Örat bland tusende röster
Hör dock ett sakta ljud,
Hör huru Anden förkunnar
Ljuvliga ting om Gud.

# 5.
Och av de himmelska skatter
Redan Du här oss ger,
Giver åt hungrande själar
Dagligen mer och mer.
