# 1.
Prisen Herren, helgon alla!
Glatt för Honom vi nedfalla
Och hans dyra namn åkalla,
Som uppstånden är!

# 2.
Jesus, Du vårt allt är bliven,
Du, som stred den svåra striden,
Vann åt oss den djupa friden,
Vi åtnjuta här.

# 3.
Gud i Dig sin vila funnit,
Och det dyra blod, som runnit,
Har åt oss försoning vunnit;
Dig ske evigt pris!

# 4.
Herre, håll oss vid din sida,
Hjälp oss ständigt Dig förbida,
Glatt i hoppet med Dig lida
Under väntan här!

# 5.
Du, vårt liv, skall uppenbaras,
Vi få se Dig och förklaras,
Som din brud med fröjd upptagas
Till din Faders hus.
