# 1.
”En Ande”, Herre stor,
Med Dig re’n här på jord!
Vad himmelskt ljus, gudomlig kraft
Som i det ordet bor!

# 2.
I din uppståndelse
Du ej allena är,
Församlingen förenar Du
Med Dig som Huvud där.

# 3.
Med fröjd vi skåda Dig
Förhärligad hos Gud.
Du älskar högt församlingen,
Som är din kropp, din brud.

# 4.
Förenade med Dig
I himlens sälla ro,
Snart till Dig själv Du för oss hem
Att evigt hos Dig bo.
