# 1.
Herre, se din lilla skara,
Samlad för att bryta bröd!
Hjälp oss för Dig stilla vara,
Då vi minnas här din död.

# 2.
Denna död, som uppenbarat
Fadrens kärlek i dess höjd,
Som ej ende Sonen sparat,
Att vi dela må hans fröjd.

# 3.
Dela Fadrens fröjd i Sonen,
Upphöjd nu och rikt belönt.
Herre Jesus, Dig vi skåda
Med all makt och ära krönt.

# 4.
Dock Du blygs ej att oss kalla
Dina bröder inför Gud,
Och i våra svaga hjärtan
Själv Du höjer lovets ljud.
