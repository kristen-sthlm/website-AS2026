# 1.
O Herre, när vi tänka på,
Hur stor din kärlek är,
Vi längta att Dig skåda få
Och vara där Du är.

# 2.
Men fast vi här i världen gå
Som i ett ökenland,
Där faror jämt vi möta få,
Dock skyddar oss din hand.

# 3.
Och i din kärlek finna vi
En sådan riklig tröst,
Att varje dag vi sjunga må
Ditt pris med gladlig röst.

# 4.
Vårt liv, vårt ljus, vår Herre kär,
Vår klippa och vår ro!
Var tanke uppå Dig oss ger
Förnyad tröst och tro.

# 5.
Vår Frälsare, ack, hjälp oss Du
Dig troget följa här
Den lilla tid, till dess vi Dig
Få skåda som Du är.
