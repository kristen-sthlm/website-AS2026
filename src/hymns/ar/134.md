# 1.
الآن وقتٌ مقبول!
انظر، الآن يوم النعمة!
يا خاطئ، ابحث عن سلام نفسك
وخذ خلاص يسوع.

# 2.
الآن وقتٌ مقبول!
انظر، يسوع يدعو الآن!
غداً ربَّما يكون متأخِّراً،
آه، لماذا تتأخَّر؟

# 3.
الآن وقتٌ مقبول!
"سنة الرب المقبولة" بنعمة؛
أيدعوك هباءً
وتحتقر نعمته؟

# 4.
الآن وقتٌ مقبول!
اسمع يسوع ينادي: تعال!
والمسيح نفسه يُبشِّرك
بأن لا يزال هناك مكان.
