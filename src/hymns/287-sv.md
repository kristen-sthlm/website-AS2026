# 1.
Hur ljuvligt mången gång
Den tanken för oss står:
I dag vi äro närmare
Vårt hemland än i går.

# C.
Närmare hemmet, närmare ja
Närmare hemmet i dag, i dag,
Än förr vi varit ha.

# 2.
Ja, närm’re fridens strand,
Där svärdet lägges ner,
Och korset byts mot kronan ut,
Den Gud de sina ger.

# 3.
Ack, närmare i dag
Vår Faders sälla hus
Med alla boningarna där,
Uppfyllda av Guds ljus.

# 4.
Ja, närmare den stund,
Då vi få se vår Gud,
Då Brudgummen skall hämta hem
Sin återlösta brud.
