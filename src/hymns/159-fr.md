# 1.
Sauveur des pécheurs, Jésus,
Il est aussi Sauveur pour moi.
Moi qui étais lié par le péché,
Par sa grâce, je suis maintenant libre.

# C.
Il est Sauveur,
Sauveur des pécheurs ici.
Il s’est donné lui-même en rançon,
Il est maintenant mon Sauveur.

# 2.
Je sais que je suis pardonné,
Heureux, justifié et libre,
Sauvé par mon Seigneur bien-aimé,
Il est Sauveur pour moi.

# 3.
Tel que j’étais, il m’a reçu,
Quand je voulais fuir le jugement.
Maintenant, il n’y a plus de condamnation,
Il est Sauveur pour moi.

# 4.
Aimé d’un amour infini,
Je reçois une riche bénédiction.
Comment chanter ses louanges ?
Il est Sauveur pour moi.

# 5.
Bientôt poindra le jour glorieux,
Où je verrai sa face.
Chante, ô mon cœur, dans la joie,
Il est Sauveur pour moi !
