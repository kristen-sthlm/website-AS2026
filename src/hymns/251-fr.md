# 1.
Ô Jésus, ton nom est une forteresse dans la détresse,
Notre bâton et notre appui, notre château fort inébranlable.
Ton nom est l’antidote le plus sûr contre la mort,
Ah, si seulement le monde entier le savait !

# 2.
Ton nom est un baume répandu qui guérit,
Apaisant et pansant l’âme blessée.
Ton nom est notre force, une puissance qui ne faillit jamais ;
Ton nom est notre refuge dans la peine et dans la joie.

# 3.
Ton nom est un rocher à l’heure de l’épreuve,
Une tour que personne ne peut abattre,
Une lumière qui dissipe les brumes les plus épaisses,
Une source qui nous donne une eau vive.

# 4.
Ton nom a aussi prouvé à mon cœur
La force de vie qui y est cachée,
Il a apaisé mon angoisse et soulagé ma douleur,
Et m’a délivré de l’effroi de la mort.

# 5.
Bien nous faut chanter ce nom glorieux,
Ô Jésus, tant que nous t’attendons ici,
Et puis pour l’éternité, de tout cœur et de toute bouche,
Proclamer combien il est grand et digne de louange.
