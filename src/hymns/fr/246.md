# 1.
En sécurité nous reposons sur ce rocher,
Où l’ennemi ne peut nous atteindre,
Nous reposons dans la forteresse puissante,
Qui tient ferme dans toutes les tempêtes.

# C.
Sur ce rocher élevé nous bâtissons
Notre espérance, notre salut ;
Il demeure ferme depuis les temps anciens,
Il demeure ferme pour l’éternité.

# 2.
Même si autour du rocher élevé
Les vagues profèrent leurs menaces sauvages,
Rien ne nous y effraie,
Car elles s’apaisent à son pied.

# 3.
Oh, quelle joie le rocher élevé
Peut nous donner à chaque instant !
Oh, quelle paix et quelle force y coulent
Abondamment de son sein !

# 4.
C’est seulement dans le rocher Christ
Que nous avons la vie et le salut ;
Fuyez donc tous les trésors de la terre,
Lui, le trésor de notre cœur, demeure.

# 5.
La pensée de ce rocher élevé
Nous remplit d’une bienheureuse espérance ;
Le cœur, l’âme et l’esprit s’élèvent
Vers les célestes espaces.
Sur ce rocher élevé,
etc.
