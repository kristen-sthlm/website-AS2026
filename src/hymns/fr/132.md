# 1.
Le sang de Jésus a frayé pour nous
Le chemin vers Dieu.
Heureux celui qui accueille maintenant
Le commandement de la grâce.

# 2.
C’est seulement par ce sang
Qu’il y a rémission.
Dieu peut maintenant accorder
Le libre pardon à tous.

# 3.
Oui, le criminel qui, dans le péché,
Devrait autrement mourir,
Par le sang de Jésus peut devenir
Blanc comme la neige.

# 4.
Maintenant, nous nous approchons du Saint
Avec une sainte hardiesse ;
Car Jésus nous a rachetés pour Dieu
Par son sang.

# 5.
Qui peut saisir la valeur du sang,
Ce saint courant,
Qui proclame encore l’amour de Dieu,
Profond et tendre !

# 6.
Seigneur Jésus, nous Te remercions
Pour ton sang précieux,
Toi qui as donné ta vie pour Tes brebis,
Bon Berger !
