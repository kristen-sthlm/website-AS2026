# 1.
L’œuvre est accomplie,
Le sang de l’offrande est versé,
Et Christ présente maintenant
Notre cause devant son Dieu ;
Notre sacrificateur, notre précieux garant,
Qui peut nous sauver parfaitement.

# 2.
La paix et le pardon,
Nous les avons reçus dans son sang.
Notre intercesseur,
Il plaide pour nous.
Lui qui a souffert la douleur de la croix ici-bas,
Maintenant nous porte sur son cœur.

# 3.
Aucun grand temple terrestre
N’est désormais son lieu de repos,
Il habite dans les hauteurs des cieux,
Notre sacrificateur pour l’éternité.
Tout ce qui n’était qu’ombre dans la loi
Est accompli en Lui, a disparu.

# 4.
Il est entré par son sang,
Le voile est déchiré, le pardon est acquis ;
Nous aussi, nous pourrons entrer
Et L’adorer là-bas,
Oui, dans le ciel même,
Nous contemplerons Jésus, le Sauveur.

# 5.
Bien qu’Il soit pour un temps
Caché aux yeux des hommes,
Bientôt le monde verra
Qu’Il n’a pas oublié son peuple.
Du ciel, Il viendra
Et rassemblera tous ses saints.
