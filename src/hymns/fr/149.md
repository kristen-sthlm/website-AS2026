# 1.
Il est un cœur qui s’émeut pour toi,
Pauvre captif lié par le péché.
Il est un œil qui guette avec ardeur,
Toujours en quête de l’enfant au loin.

# 2.
Il est une oreille qui s’incline
Pour entendre le pauvre implorant secours ;
Il est une langue qui parle avec douceur
À celui qui est dans la misère et l’affliction.

# 3.
Il est une source pour toi qui as soif,
Pour toi qui as faim, il est un pain ;
Il est un refuge, sûr et tranquille,
Pour toi que poursuivent le péché et la mort.

# 4.
Oh, viens à Jésus, et tu trouveras
Tout ce dont tu as besoin pour le salut,
Car Jésus, Jésus, oui, lui seul
Suffit à tous pour l’éternité.
