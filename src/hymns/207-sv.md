# 1.
O Du, som sade: Ingen kan
De mina från Mig taga,
Dig mot allting vi ropa an,
Som vill oss från Dig draga.
Led oss på livets stig med dem,
Som till din Faders sälla hem
Du lovat att ledsaga.

# 2.
Lär oss din röst att känna nu
Och gå dit Du vill kalla.
Den ”klena hjorden” älskar Du,
Du räknat fåren alla.
Du söker den som vilse far,
Den svaga i din famn Du tar,
Upprättar dem som falla.
