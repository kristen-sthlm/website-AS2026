# 1.
Es-tu dans la détresse,
Sans aucun soutien,
Te sens-tu rejeté,
Le Seigneur est riche,
Toujours le même,
Jamais sa porte n’est fermée.

# 2.
Riche en grâce,
Il connaît aussi le remède,
Dis-lui ce qui te manque ;
Que ce soit grand ou petit,
Dis-le-lui seulement,
Il te partagera son secours.

# 3.
Même si
Beaucoup de tes amis te trahissent,
Le Seigneur est le rocher sûr.
Il est fidèle,
Il te garde son amour,
Tu peux bâtir sur lui.

# 4.
Il a le secours,
Prêt et prompt
Pour toi au bon moment.
Le jour de l’épreuve,
Avec le bon plaisir de Dieu,
Sera bientôt passé.

# 5.
Prends seulement courage,
Le Seigneur est bon,
Il agit dans l’amour.
Le pain des larmes,
La plus dure détresse,
Il les transforme en joie.

# 6.
Jésus, ton nom
Est le port le plus sûr
Dans tous les changements ;
Consolation dans la détresse,
Vie au milieu de la mort,
Lumière encore auprès du tombeau.
