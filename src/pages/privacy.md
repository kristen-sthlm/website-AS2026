*Senast uppdaterad: maj 2026.*

## Sammanfattning

Den här webbplatsen samlar inte in någon personlig information om dig. Inga cookies sätts, ingen besöksstatistik förs, inga spårningsverktyg används.

Webbplatsen är statisk: alla sidor består av text, bilder och ljud som laddas direkt till din webbläsare. Inga formulär, ingen registrering, ingen anpassning sker baserat på vem du är.

## Vad utgivaren samlar in

**Ingenting.** Ingen tillgång till och samlar inte in någon information om besökarna på den här webbplatsen.

## Externa resurser

Webbplatsen laddar inga externa skript, typsnitt, bilder eller ljud från tredjepartsservrar. Alla typsnitt, stilar, ljudfiler och bilder serveras från samma domän som sidorna själva.

## Vad vår tjänsteleverantör (GitHub) hanterar

Webbplatsen är publicerad via GitHub Pages, en tjänst som drivs av GitHub, Inc. (ett dotterbolag till Microsoft Corporation).

När du besöker webbplatsen registrerar GitHub vissa tekniska uppgifter för att kunna driva tjänsten säkert och förebygga missbruk. Detta inkluderar:

- Din IP-adress
- Tekniska uppgifter om din webbläsare och enhet (User-Agent-sträng, hänvisande sida)
- Tidpunkt för besöket

GitHub är personuppgiftsbiträde för denna behandling. Behandlingen sker i enlighet med GitHubs egen integritetspolicy:

[https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

GitHubs servrar för Pages-tjänsten finns delvis utanför EU. Överföringen sker med stöd av Standardavtalsklausuler enligt artikel 46 i GDPR. För närmare information, se GitHubs egen redogörelse.

## Kontaktformulär

Vårt kontaktformulär hanteras av tjänsten **Tally** (Tally Forms BV, Belgien). När du skickar in formuläret behandlas dina uppgifter — inklusive de fält du fyllt i samt teknisk information som IP-adress — av Tally i enlighet med deras integritetspolicy:

[https://tally.so/help/privacy-policy](https://tally.so/help/privacy-policy)

Tally är personuppgiftsbiträde för denna behandling. Du väljer själv om du vill använda formuläret; ingen behandling sker om du inte aktivt skickar in ett meddelande.

## Dina rättigheter enligt GDPR

Eftersom utgivaren inte behandlar några personuppgifter har du inte några uppgifter att begära från oss. Om du vill utöva rättigheter gentemot GitHub i egenskap av personuppgiftsbiträde, hänvisar vi till deras integritetspolicy ovan.
